# Настройка Custom GPT

## Поля GPT Builder

### Название

`humanizer+ru · Русский редактор`

Пока репозиторий не переименован, старое внутреннее имя может сохраняться в технических файлах.

### Описание

Редактор русского текста: сначала проверяет норму, смысл и естественный русский дискурс, затем убирает канцелярит, кальки и AI-шаблоны. Сохраняет нормативные тире, двоеточия, эллипсис, противопоставления, профессиональную лексику и авторский голос.

### Instructions

Скопируй целиком `gpt/INSTRUCTIONS.md` в поле **Instructions**.

Правила поведения должны быть в Instructions. Knowledge используется как справочный материал.

## Knowledge

Загрузи следующие reference-файлы:

1. `references/russian-language.md`
2. `references/rule-audit.md`
3. `references/nora-gal.md`
4. `references/author-profile.md`
5. `knowledge/corrections.md`
6. `scripts/lint.py`
7. `SKILL.md`

`references/patterns.md` пока **не загружай в Knowledge**. Он остаётся историческим справочником апстрима и содержит старые hard bans, которые противоречат новой иерархии. После полной переписи паттернов файл можно вернуть в Knowledge.

Не загружай `evals/*.json` в Knowledge: это тестовые наборы, а не редакционные справочники.

`profile_author.py` тоже не нужен в Knowledge. Его запускают отдельно для построения авторского `profile.json`; сам профиль можно загрузить при работе с конкретным автором.

## Возможности

Включить:

- **Web Search** — для текущих и спорных фактов;
- **Code Interpreter & Data Analysis** — для `lint.py` и анализа author profile.

Canvas для этого GPT не требуется: актуальные модели ChatGPT поддерживают редактируемые writing/code blocks прямо в чате, а совместимость Canvas зависит от модели.

Image generation, Apps и Actions для базового редактора не нужны.

### Рекомендуемая модель

Выбери наиболее сильную доступную модель, которая поддерживает нужные capabilities. Не закрепляй документацию за конкретным номером модели: список доступных моделей меняется.

## Подсказки для начала разговора

1. `Отредактируй текст. Сохрани мой голос, тезис и силу формулировок.`
2. `Проведи аудит без переписывания: отдели ошибки русского от AI-паттернов.`
3. `Сделай текст естественнее по-русски: проверь порядок слов, эллипсис и кальки.`
4. `Подстрой текст под мой идиолект по загруженному profile.json.`

## Иконка

Используй текущую иконку проекта или новую после переименования. Это не влияет на методику редактора.

## Перед публикацией

Прогони:

- `gpt/TESTS.md`;
- `evals/nora-gal.json`;
- `evals/russian-language.json`;
- `python3 scripts/lint.py --self-test`.

Критический провал, если GPT:

- ломает нормативную пунктуацию ради anti-detection;
- считает `не X, а Y` hard ban;
- заменяет тире дефисом;
- игнорирует тему/рему и контекстные опущения;
- имитирует ошибки автора без прямой просьбы;
- выдумывает факты ради конкретики.

## Сборка в интерфейсе

По актуальной справке OpenAI GPT создаётся и настраивается в веб-редакторе GPTs: отдельно задаются Instructions, Knowledge и Capabilities. После изменений обязательно используй Preview.

1. Открой GPT editor в веб-версии ChatGPT.
2. Заполни Name, Description и Conversation starters.
3. Вставь `gpt/INSTRUCTIONS.md` в Instructions.
4. Загрузи reference-файлы в Knowledge.
5. Включи Web Search и Code Interpreter & Data Analysis.
6. Проверь GPT в Preview.
7. Прогони smoke/eval-сценарии выше.
8. Сохрани приватно до завершения проверки.

## Обновление

После изменений в репозитории:

- заново скопируй Instructions, если они менялись;
- замени изменившиеся Knowledge-файлы;
- повтори evals;
- проверь, что публичное описание не обещает функций, которых нет в текущей конфигурации.
