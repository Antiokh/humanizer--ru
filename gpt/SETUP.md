# Настройка Custom GPT

## Поля GPT Builder

### Название

`humanizer--ru · Русский редактор`

### Описание

Редактор русского текста: убирает канцелярит, воду и AI-слоп, сохраняя факты, голос, резкость и нормальную типографику. Проверяет, звучит ли фраза по-русски и принадлежит ли она автору. Нормативное тире «—» разрешено; шаблонный переизбыток получает предупреждение.

### Instructions

Скопируй целиком содержимое файла `gpt/INSTRUCTIONS.md` в поле **Instructions**.

Не загружай этот файл как Knowledge вместо вставки в Instructions: правила поведения должны находиться именно в инструкциях GPT.

## Knowledge

Загрузи пять файлов по отдельности:

1. `references/patterns.md`
2. `references/nora-gal.md`
3. `knowledge/corrections.md`
4. `scripts/lint.py`
5. `SKILL.md`

`patterns.md` содержит 34 базовых паттерна. `nora-gal.md` добавляет паттерны 35–39: конкретность, голос, совместимость образов, сочетаемость и естественный русский синтаксис. `corrections.md` хранит приоритетные правила владельца. `lint.py` нужен для детерминированной проверки через Code Interpreter. `SKILL.md` остаётся полной картой исходного скилла и резервным источником правил.

Не загружай файлы из `evals/` в Knowledge: это тестовые наборы, а не редакционные справочники.

## Возможности

Включить:

- **Web Search** — для проверки текущих и спорных фактов;
- **Canvas** — для длинных текстов и последовательной доработки;
- **Code Interpreter & Data Analysis** — обязателен для запуска `lint.py`.

Выключить:

- **Image generation** — редактору не нужна;
- **Apps** — пока не нужны;
- **Actions** — пока не нужны.

### Рекомендуемая модель

Выбери наиболее сильную доступную модель класса **Thinking**. Если в списке есть GPT-5.6 Thinking, используй её.

## Подсказки для начала разговора

1. `Отредактируй текст. Сохрани мой голос, тезис и силу формулировок.`
2. `Проведи аудит без переписывания: покажи слабые места и фактические риски.`
3. `Сделай текст короче и живее, не потеряв ни одного факта.`
4. `Проверь, звучит ли текст по-русски и не заговорил ли автор чужим голосом.`

## Иконка

Используй портрет редактора с намёком на Пушкина: шляпа, бакенбарды и круглые очки. Иконка должна оставаться читаемой в маленьком круге.

## Доступ

На первом этапе оставь GPT в режиме **Only me**. После тестов можно открыть доступ по ссылке. Публичная публикация имеет смысл только после проверки сценариев из `gpt/TESTS.md` и `evals/nora-gal.json`.

## Сборка в интерфейсе

1. Открой веб-версию ChatGPT.
2. Перейди в **Explore GPTs → Create**.
3. Открой режим **Configure**.
4. Заполни Name, Description и Conversation starters из этого файла.
5. Вставь `gpt/INSTRUCTIONS.md` в Instructions.
6. Загрузи пять Knowledge-файлов.
7. Включи Web Search, Canvas и Code Interpreter & Data Analysis.
8. Проверь GPT в Preview по `gpt/TESTS.md`.
9. Дополнительно прогони сценарии из `evals/nora-gal.json`.
10. Сохрани как **Only me**.

## Обновление

После изменений в репозитории:

- заново скопируй `gpt/INSTRUCTIONS.md`, если менялись правила поведения;
- замени изменившиеся Knowledge-файлы в GPT Builder;
- повтори smoke-тесты;
- используй историю версий GPT, чтобы можно было откатить неудачную конфигурацию.
