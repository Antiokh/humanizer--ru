# Humanizer RU

Форк [smixs/humanizer-ru](https://github.com/smixs/humanizer-ru) с менее агрессивным отношением к русской типографике.

Скилл для AI-агентов: Claude Code, Codex, OpenClaw, Hermes и любых других, читающих SKILL.md. Берёт русский текст после нейросети и убирает всё, по чему его палят: канцелярит, «не просто X, а Y», шаблонные конструкции, штампы и воду. Факты и цифры не трогает.

Работает в три шага. Сначала ищет проблемы по справочнику из 34 паттернов, потом чинит только найденное, в конце гоняет чистовик через линтер - питоновский скрипт, который ловит жёсткие запреты. Чистый текст возвращает как есть: повторная редактура хорошего текста его портит.

## Чем отличается этот форк

- Нормативное длинное тире «—» разрешено. Линтер выдаёт `WARN` только при подозрительно высокой плотности тире, а не `ERROR` за каждый знак.
- Дефис «-» не используется как механическая замена русского тире.
- Для вложенных цитат явно заданы „немецкие лапки“.
- Заголовки оформляются как обычные предложения: с заглавной буквы первое слово и имена собственные.

Апстрим сознательно использует более жёсткую anti-detection эвристику и запрещает длинное тире полностью. Этот форк сохраняет типографически правильные тире, но всё равно ловит их шаблонное переиспользование.

## Установка

Через skills CLI:

```bash
npx skills add Antiokh/humanizer-ru        # спросит, куда ставить
npx skills add Antiokh/humanizer-ru -g     # глобально, для всех проектов
npx skills update humanizer-ru             # обновление
```

Или руками (Claude Code):

```bash
git clone https://github.com/Antiokh/humanizer-ru.git ~/.claude/skills/humanizer-ru
```

## Использование

```
/humanizer-ru

[ваш текст]
```

В любом агенте достаточно попросить: «очеловечь этот текст», «убери воду», «очисти от признаков AI».

## Как это проверяется

18 eval-сценариев, 121 проверка: сохранность фактов и цифр, ловушки на замену слопа синонимами, чистые тексты, которые нельзя трогать. Линтер `scripts/lint.py` - обычный python3 без зависимостей; без питона скилл работает по ручному чеклисту.
