# humanizer--ru

Русский humanizer, который убирает AI-слоп, но не ломает русскую типографику ради антидетект-эвристики.

Это форк [smixs/humanizer-ru](https://github.com/smixs/humanizer-ru). Основа, справочник паттернов и большая часть логики остаются совместимыми с апстримом. Намеренное различие одно: нормативное длинное тире «—» не считается автоматическим признаком нейросети.

Два дефиса в названии отделяют этот вариант от апстрима и сразу показывают, что правила типографики здесь отличаются.

## Главное различие

| Правило | `smixs/humanizer-ru` | `Antiokh/humanizer--ru` |
|---|---|---|
| Одно нормативное длинное тире | `ERROR`, требуется заменить | Допустимо |
| Частое шаблонное употребление тире | Ловится тем же полным запретом | `WARN` по плотности, решение принимает редактор |
| Замена тире дефисом `-` | Используется как anti-detection правило | Запрещена как типографическая ошибка |

Апстрим сознательно оптимизирует текст под сокрытие AI-происхождения: длинное тире считается сильным маркером и запрещается целиком. Этот форк разделяет знак и паттерн. Само тире нормально для русского языка; подозрительным может быть его механическое повторение в каждом втором предложении.

Вложенные кавычки и обычная капитализация заголовков уже приняты апстримом и не заявляются как отдельное преимущество форка.

## Что делает скилл

Скилл для AI-агентов: Claude Code, Codex, OpenClaw, Hermes и других систем, читающих `SKILL.md`. Он редактирует готовый русский текст:

- убирает канцелярит, воду и шаблонные AI-конструкции;
- сохраняет факты, цифры, авторскую позицию и странные живые детали;
- сначала проводит аудит, потом правит только найденные места;
- проверяет чистовик детерминированным Python-линтером;
- возвращает чистый текст без бессмысленного повторного переписывания.

В справочнике 34 паттерна: негативные параллелизмы, рекламные штампы, псевдоглубина, математическая нотация в прозе, рубленый драматизм, повтор глаголов, стопки несвязанных абзацев и другие признаки машинного текста.

## Изменения форка

- **05.08.2026:** длинное тире переведено из жёсткой ошибки в предупреждение при подозрительно высокой плотности;
- правила в `SKILL.md`, линтер и self-test синхронизированы;
- дефис больше не предлагается как механическая замена тире;
- исправлены формулировки правил кавычек и капитализации заголовков.

История изменений исходного проекта находится в [CHANGELOG.md](CHANGELOG.md).

## Установка

Через skills CLI:

```bash
npx skills add Antiokh/humanizer--ru
npx skills add Antiokh/humanizer--ru -g
```

Или вручную для Claude Code:

```bash
git clone https://github.com/Antiokh/humanizer--ru.git ~/.claude/skills/humanizer-ru
```

Внутреннее имя скилла пока сохраняется как `humanizer-ru`, поэтому существующие команды и установки не ломаются:

```text
/humanizer-ru

[ваш текст]
```

В любом агенте можно написать: «очеловечь этот текст», «убери воду», «очисти от признаков AI».

## Проверка

В репозитории 18 eval-сценариев и 121 проверка: сохранность фактов и цифр, ловушки на замену одного слопа другим, а также чистые тексты, которые нельзя трогать.

Линтер `scripts/lint.py` работает на обычном Python 3 без зависимостей. Нормативное тире проходит проверку. Высокая плотность тире даёт предупреждение, но не блокирует результат автоматически.

```bash
python3 scripts/lint.py --self-test
python3 scripts/lint.py текст.md
```
