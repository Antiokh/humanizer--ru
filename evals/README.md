# Eval-наборы

`evals/evals.json` унаследован от апстрима и сохраняет его исторические сценарии. Часть старых expectations всё ещё формулирует полный запрет длинного тире. Для `humanizer--ru` такие assertions не являются нормативными: форк разрешает корректное русское тире и предупреждает только о шаблонном переизбытке.

Для проверки отличий форка используй:

- `evals/fork-smoke.json` — машинно читаемый минимальный набор по типографической политике;
- `evals/nora-gal.json` — шесть смысловых сценариев по паттернам 35–39;
- `gpt/TESTS.md` — ручные сценарии для Preview в Custom GPT;
- `python3 scripts/lint.py --self-test` — проверка детерминированного линтера.

## Типографическая политика

При переносе апстримных eval-сценариев в активный гейт замени требования вида «в тексте нет длинного тире» на две отдельные проверки:

1. нормативное тире допустимо и не заменяется дефисом;
2. шаблонная высокая плотность тире должна быть замечена и оценена по контексту.

До полной миграции не используй запрет тире из `evals/evals.json` как критерий провала форка.

## Семантический слой

`evals/nora-gal.json` проверяет:

1. раскрытие пустых абстракций без выдумывания фактов;
2. соответствие речи голосу и ситуации;
3. устранение конфликтующих метафор;
4. нормальную русскую сочетаемость;
5. отказ от кальки чужого синтаксиса;
6. сохранение смыслового ударения и степени уверенности.

Эти сценарии нельзя свести к поиску запрещённых слов. Оценка должна учитывать смысл, голос и контекст. Нормативное длинное тире внутри ответов допустимо.
